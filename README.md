# 📱 Custom 
레이아웃을 자유롭게 커스터마이징할 수 있는 안드로이드 키보드 앱입니다.

## ✨ 주요 기능

- **다국어 입력 지원**
  - 한글 2벌식 (자음+모음 실시간 조합)
  - 한글 천지인 (획 조합 + 자음 다중탭)
  - 베트남어 (성조/발음기호 조합 키)
  - English
  - 언어를 직접 추가하고 편집 가능
- **키보드 레이아웃 커스터마이징**
  - 실제 키보드 미리보기에서 바로 편집
  - 키 추가/삭제/이동, 너비 조절
  - 길게 눌렀을 때 나오는 특수문자(팝업) 설정
  - 다른 언어로 키 복사/이동
- **테마 꾸미기**
  - 배경: 단색 / 그라데이션(방향·원형) / 이미지
  - 키 색상, 키 테두리(단색·그라데이션)
  - 키보드 크기, 키 사이 간격 조절
  - 폰트 변경 (기본/고딕체/명조체/고정폭/직접 업로드)
- **클립보드**
  - 키보드 상단 고정 버튼으로 열고 닫기
  - 최근 복사 항목 기록, 순서 변경, 삭제
- 시스템 표준 키보드 진동/클릭음 지원

## 🛠️ 빌드 방법

### Android Studio
1. 이 저장소를 다운로드(zip)한 뒤 압축을 풀어주세요.
2. Android Studio에서 `Open`으로 프로젝트 폴더를 엽니다.
3. Gradle Sync가 끝나면 ▶ 버튼으로 실행합니다.

### GitHub Actions (컴퓨터 없이도 빌드 가능)
저장소에 포함된 `.github/workflows/build.yml`이 자동으로 APK를 빌드합니다.
`Actions` 탭 → 완료된 workflow → `Artifacts`에서 APK를 내려받을 수 있습니다.
